# Contributing

Thanks for improving GenAI Guardrails.

Good contributions are self-contained explanations, primary standards or research, maintained open-source tools, scenario recipes, threat-model improvements, or corrections to safety guidance.

Every new example should identify the threat, state the trust boundary, show the policy decision, avoid real secrets, include a safe fallback, and explain how to test false positives and false negatives.

Quiz questions must test concepts explained here, have at least two correct answers, include an explanation and source link, and avoid ephemeral vendor limits.

Run the quiz tests before opening a pull request:

```bash
cd quiz
npm test
```

By contributing, you agree that your contribution will be licensed under this repository's MIT License.
