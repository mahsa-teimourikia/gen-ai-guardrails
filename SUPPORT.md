# Support

GenAI Guardrails is a community-maintained learning repository rather than a hosted support service.

## Before opening an issue

1. Start from the current `main` branch.
2. Follow the setup steps in the root [README](README.md).
3. Search existing issues and pull requests.
4. Run the focused validation command for the affected component.
5. Reduce failures to a smallest reproducible example and remove secrets or private data.

## Where to ask

- Use the **bug report** form for reproducible failures in code, tests, CI, or the quiz.
- Use the **curriculum or documentation improvement** form for technical corrections, unclear lessons, or broken references.
- Use the **feature request** form for a new capability or learning outcome.
- Use [private vulnerability reporting](https://github.com/mahsa-teimourikia/gen-ai-guardrails/security/advisories/new) for suspected vulnerabilities.

General consulting, production deployment support, and debugging of substantially modified forks are outside this repository's support scope.
